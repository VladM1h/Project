#Project practicum
    Приложение для просмотра погоды с использованием Яндекс.Погода API.Этот учебный проект предсавляет собой веб-приложение, которое позволяет пользователям получать актуальную информацию о погоде в любом городе мира. Приложение использует API Яндекс.Погоды для получения данных и отображает их в удобном и понятном интерфейсе.

## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/VladM1h/Project.git
    cd Project
    ```
2. Получите API ключ на Яндекс.Погода API
    https://yandex.ru/dev/weather/
3. Перейдите в файл script
    Поместите в константу accessKey полученный API
## Использование
  Откройте файл index.html через доступный браузер.

  ## Структура проекта
   - index.html : Основной HTML файл
   - script.js : Стили приложения
   - styles.css : JavaScript логика
   - README.md : Документация проекта
