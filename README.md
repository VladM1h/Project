# Project practicum
Приложение для просмотра погоды с использованием Яндекс.Погода API.Этот учебный проект представляет собой веб-приложение, которое позволяет пользователям получать актуальную информацию о погоде городов Калининградской области. Приложение использует API Яндекс.Погоды для получения данных и отображает их в удобном и понятном интерфейсе.

## Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/VladM1h/Project.git
    cd Project
    ```
2. Получите API ключ на Яндекс.Погода API
    https://yandex.ru/dev/weather/

## Использование
1. Откройте файл index.html через доступный браузер.
2. Вставляем в поле ввода скопированный API.
3. Нажмите на кнопку "Разблокировать CORS-прокси"
4. В новой вкладке нажимаем на кнопку "Request temporary access to the demo server"
5. Закрываем вкладку и переходим в "Прогноз погоды"
6. Подтверждаем ключ и прокси
7. Далее выбираем город и смотрим погоду!)
